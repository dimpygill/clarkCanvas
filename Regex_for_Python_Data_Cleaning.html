Regular Expressions (Regex) for Python Data Cleaning

This document introduces regular expressions from the beginning and then applies them to realistic Python and Pandas data-cleaning tasks.

1. Why Regex Is Useful

A regular expression, usually called regex, is a pattern used to search, identify, validate, extract, split, or replace text.

Ordinary string replacement works well when we know the exact text:

text = "John-Smith" print(text.replace("-", " "))
John Smith

But dirty data is often unpredictable. A name might contain one space, two spaces, five spaces, or a tab. Regex lets us describe the pattern instead of every possible exact value.

2. Our Starting Example: Repeated Spaces

df["name"] = df["name"].str.replace(r"\s+", " ", regex=True)

Suppose the values are:

BeforeAfter
John    SmithJohn Smith
Maria   LopezMaria Lopez
David  LeeDavid Lee

Break the pattern r"\s+" into pieces:

PartMeaning
rPython raw-string prefix. Helpful when writing backslashes.
\sMatch a whitespace character.
+Match one or more occurrences of the item immediately before it.
\s+Therefore: match one or more consecutive whitespace characters.

The replacement value is one normal space: " ". So every group of whitespace becomes exactly one space.

3. What Does regex=True Mean?

In Pandas:

df["name"].str.replace(r"\s+", " ", regex=True)

regex=True tells Pandas: interpret the first argument as a regex pattern.

Pattern: what should Python find?
Replacement: what should Python put there instead?

4. Why Do We Write r"..."?

Regex frequently uses backslashes, such as \d, \s, and \w. Python also uses backslashes for escape sequences. A raw string makes regex patterns easier to read.

pattern = r"\d+"

For beginner regex code, using raw strings for patterns is a good habit.

5.1 What exactly is a “word character”?

In regex, word character does not mean a complete English word. It is simply the name regex gives to a category of individual characters.

In Python regex, \w matches one word character: generally a letter, a digit, or an underscore.

For John_123, every character is matched by \w:

J o h n _ 1 2 3 ✓ ✓ ✓ ✓ ✓ ✓ ✓ ✓

For John-Smith, the hyphen is not a word character:

J o h n - S m i t h ✓ ✓ ✓ ✓ ✗ ✓ ✓ ✓ ✓ ✓

Difference between \w and \S

\S is much broader. It matches anything that is not whitespace. Therefore punctuation such as @, -, and . is matched by \S, but not by \w.

Character\S\w

Easy memory rule:
\s = whitespace    \S = NOT whitespace
\w = word character (letter/digit/underscore)    \W = NOT a word character

What does \w+ mean?

\w matches one word character, while + means one or more. Therefore \w+ matches a consecutive group of word characters.

import re text = "John Smith 123" print(re.findall(r"\w+", text))
['John', 'Smith', '123']

Notice that regex calls 123 a match for \w+ even though humans would not normally call 123 a word. This is why word character is technical regex terminology.

Python note: By default, Python 3 regex is Unicode-aware, so \w can match many letters and digits beyond basic English A-Z. For an introductory course, “letters, digits, and underscore” is the useful rule to remember.

5.2 Find digits

import re text = "Student GPA is 3.8" result = re.findall(r"\d", text) print(result)
['3', '8']

5.2 Remove non-digits from a phone number

import re phone = "(503) 555-2345" clean_phone = re.sub(r"\D", "", phone) print(clean_phone)
5035552345

\D means “anything that is not a digit.” re.sub() replaces every matched character with an empty string.

7. Anchors: Beginning and End

SymbolMeaning
^Beginning of the string
$End of the string

For example, a five-digit ZIP code can be described as:

r"^\d{5}$"

Read it as: beginning → exactly five digits → end.

import re print(bool(re.fullmatch(r"\d{5}", "97201"))) print(bool(re.fullmatch(r"\d{5}", "9720A")))
True False

9. Alternation: OR with |

pattern = r"CS|CIS|IT"

This means match CS OR CIS OR IT.

import re text = "Major: CS" print(re.findall(r"CS|CIS|IT", text))
['CS']

10. Groups with Parentheses

Parentheses group parts of a pattern. They are especially useful for extracting pieces of structured text.

import re phone = "503-555-1234" match = re.fullmatch(r"(\d{3})-(\d{3})-(\d{4})", phone) print(match.group(1)) print(match.group(2)) print(match.group(3))
503 555 1234

11. Escaping Special Regex Characters

Some characters have special regex meanings: ., +, *, ?, ( ), [ ], { }, ^, $, and |.

If you want an actual period, use \..

r"\."

For example, to find the period in 503.555.9999, use \., not just ..

12. Core Python re Operations

12.1 re.search() — find a pattern somewhere

import re text = "Student ID: 12345" match = re.search(r"\d+", text) if match: print(match.group())
12345

12.2 re.findall() — return all matches

import re text = "Scores: 90, 85, 100" numbers = re.findall(r"\d+", text) print(numbers)
['90', '85', '100']

12.3 re.sub() — replace matches

import re text = "John Smith" clean = re.sub(r"\s+", " ", text) print(clean)
John Smith

12.4 re.split() — split using a pattern

import re text = "Python,Java;C#" languages = re.split(r"[,;]", text) print(languages)
['Python', 'Java', 'C#']

12.5 re.fullmatch() — validate the whole string

import re phone = "5035551234" if re.fullmatch(r"\d{10}", phone): print("Valid") else: print("Invalid")
Valid

D. The Same Phone-Cleaning Task Three Ways

This comparison shows why the functions can look similar while behaving differently.

ApproachCodeWhen to Use It
Python ordinary stringphone.replace("-", "")One string; exact known text such as a hyphen.
Python regexre.sub(r"\D", "", phone)One string; remove anything matching a pattern.
Pandas regexdf["phone"].str.replace(r"\D", "", regex=True)An entire DataFrame column; remove anything matching a pattern.

Example data:

(503) 555-2345 503-555-1234 503.555.9999 503/555/4567

With Python regex, one individual value can be cleaned with:

clean_phone = re.sub(r"\D", "", phone)

With Pandas, an entire column can be cleaned with:

df["phone"] = df["phone"].str.replace( r"\D", "", regex=True )

Both use the same regex pattern \D. The difference is the API being used: re.sub() works directly with a Python string, while Pandas .str.replace() applies the operation across a Series.

13. Regex with Pandas

Pandas provides regex support through many .str operations.

13.1 Replace patterns: .str.replace()

df["name"] = df["name"].str.replace( r"\s+", " ", regex=True )

13.2 Check whether values contain a pattern: .str.contains()

# Find rows whose major contains "science" result = df[df["major"].str.contains( r"science", case=False, na=False, regex=True )]

13.3 Validate complete values: .str.fullmatch()

# True when the phone contains exactly 10 digits valid_phone = df["phone"].str.fullmatch( r"\d{10}", na=False )

13.4 Extract part of a value: .str.extract()

# Extract a 5-digit ZIP code df["zip"] = df["address"].str.extract(r"(\d{5})")

14. Practical Data-Cleaning Operations

14.1 Remove repeated internal spaces

df["name"] = df["name"].str.replace( r"\s+", " ", regex=True )

Pattern: \s+ = one or more whitespace characters.
Replacement: one space.

14.2 Remove all non-digit characters from phone numbers

Dirty values:

(503) 555-2345 503-555-1234 503.555.9999 503 555 4567
df["phone"] = df["phone"].str.replace( r"\D", "", regex=True )

Result:

5035552345 5035551234 5035559999 5035554567

14.3 Find phone numbers that are not exactly 10 digits

valid = df["phone"].str.fullmatch(r"\d{10}", na=False) invalid_rows = df[~valid]

14.4 Remove unwanted punctuation from names

df["name"] = df["name"].str.replace( r"[^A-Za-z\s'-]", "", regex=True )

This example keeps English letters, whitespace, apostrophes, and hyphens. Real-world name validation should be designed carefully because names can contain characters from many writing systems.

14.5 Extract numbers from mixed text

Suppose:

"GPA: 3.8" "Score: 95"
df["number"] = df["text"].str.extract( r"(\d+(?:\.\d+)?)" )

The pattern allows an integer or a decimal number.

14.6 Identify values containing digits

has_number = df["name"].str.contains( r"\d", na=False, regex=True ) print(df[has_number])

This can help identify suspicious values such as John123 in a name column.

14.7 Clean multiple kinds of whitespace

df["name"] = ( df["name"] .str.strip() .str.replace(r"\s+", " ", regex=True) )

.str.strip() removes whitespace at the beginning and end. Regex then collapses repeated internal whitespace.

A simple classroom-level pattern is:

r"^[^@\s]+@[^@\s]+\.[^@\s]+$"

16. Date Pattern Example

To recognize the shape MM/DD/YYYY:

r"\d{2}/\d{2}/\d{4}"

Examples:

05/12/2004 → matches pattern 5/12/2004 → does not match this exact pattern 2004-05-12 → does not match
Matching a date pattern does not prove the date is valid. For example, 99/99/2025 has the right shape but is not a real date. Use pd.to_datetime() for actual date conversion/validation.

19. Reading Regex from Left to Right

Do not try to memorize a complicated expression as one object. Break it into pieces.

Example:

r"^\d{3}-\d{3}-\d{4}$"
PieceRead it as
^start
\d{3}exactly 3 digits
-hyphen
\d{3}exactly 3 digits
-hyphen
\d{4}exactly 4 digits
$end
START → 3 digits → - → 3 digits → - → 4 digits → END

20. Common Beginner Mistakes

Mistake 1: Forgetting regex=True

When using a regex pattern with Pandas replacement, explicitly specify regex=True.

Mistake 2: Confusing \d with \D

\d = digit. \D = NOT a digit.

Mistake 3: Using . when you mean an actual period

. has a special regex meaning. Use \. for a literal period.

Mistake 4: Using regex when a normal string method is clearer

For example, use .str.strip() for leading/trailing whitespace rather than writing an unnecessarily complex regex.

Mistake 5: Treating pattern matching as semantic validation

A value can have the correct format and still be logically invalid. Regex checks text patterns; business rules and type-aware functions perform deeper validation.

24. Final Takeaway

Regex is a language for describing text patterns. In data cleaning it is particularly useful when values are inconsistent but follow recognizable patterns.

Think in this order:
1. What does the dirty data look like?
2. What pattern identifies the unwanted or required text?
3. Do I want to find, validate, extract, split, or replace it?
4. Is regex actually the clearest tool for the job?
5. Validate the result after cleaning.
