1 Overview

You have been given a CSV file called students_dirty.csv — a student enrollment dataset that was exported from a poorly maintained system. The data contains a mix of clean and dirty records across six columns.


Your job is to load the file with Pandas, clean every column systematically, and print a structured summary that documents what you found and fixed. The tutorial shared in class covers all the techniques you need — treat this as your opportunity to apply them on real data.


You will work in a single Jupyter Notebook (or .py file). Organize your code with one cell (or section) per task. Comments are expected.

2 Learning Objectives
  • Load a CSV safely while preserving data types (e.g., string IDs with leading zeros)
  • Detect and remove exact duplicate rows

  • Standardize string columns — strip whitespace, fix capitalization, reconcile synonyms
  • Validate and clean numeric columns (GPA range, type coercion)
  • Normalize phone numbers and date strings to a single consistent format
  • Produce a written data-quality summary report in code

Task 5

Clean and Validate the gpa Column

GPA cleaning has several sub-steps. Work through them in order:

  • Step A: Replace non-standard null markers (N/A, unknown, -) with NaN
  • Step B: Replace text values that can't be parsed ("three point five", "four point oh", "2.5 GPA") with NaN
  • Step C: Use pd.to_numeric(..., errors="coerce") to convert the column — anything still non-numeric becomes NaN
  • Step D: Flag rows where GPA is outside 0.0 – 4.0 and set them to NaN
# A + B: replace known bad values
BAD_GPA = ["N/A", "unknown", "-",
           "three point five", "four point oh", "2.5 GPA"]
df["gpa"] = df["gpa"].replace(BAD_GPA, pd.NA)

# C: coerce to numeric
df["gpa"] = pd.to_numeric(df["gpa"], errors="coerce")

# D: out-of-range → NaN
invalid_gpa = (~df["gpa"].between(0.0, 4.0)) & df["gpa"].notna()
invalid_gpa_count = invalid_gpa.sum()
df.loc[invalid_gpa, "gpa"] = pd.NA
Note: Do not fill missing GPAs with a value like 0 or the column mean — leave them as NaN and report the count in your summary. Silently filling missing academic records is bad practice.
Task 6

Normalize the phone Column

Target format: (XXX) XXX-XXXX (10-digit US phone numbers only).

  • Strip all non-digit characters, then check digit count
  • If the result is 11 digits starting with 1, remove the country code
  • If the result is exactly 10 digits, reformat to (XXX) XXX-XXXX
  • Otherwise, the value is invalid — set to NaN
import re

def clean_phone(val):
    if pd.isna(val):
        return pd.NA
    digits = re.sub(r"\D", "", str(val))
    if len(digits) == 11 and digits[0] == "1":
        digits = digits[1:]
    if len(digits) == 10:
        return f"({digits[:3]}) {digits[3:6]}-{digits[6:]}"
    return pd.NA   # invalid

df["phone"] = df["phone"].apply(clean_phone)

Count how many rows ended up with NaN after cleaning — those are invalid phones.

Task 7

Parse and Standardize date_of_birth

Target format: YYYY-MM-DD. The file has four formats, and one (DD/MM/YYYY) is ambiguous with MM/DD/YYYY.

Your strategy: replace text markers with NaN, then use pd.to_datetime with dayfirst=False and errors="coerce". Dates where the day part > 12 are unambiguous; ambiguous ones will be parsed as MM/DD.

BAD_DATES = ["not available", "N/A", "unknown"]
df["date_of_birth"] = df["date_of_birth"].replace(BAD_DATES, pd.NA)

df["date_of_birth"] = pd.to_datetime(
    df["date_of_birth"],
    dayfirst=False,
    errors="coerce"
).dt.strftime("%Y-%m-%d")
Hint: Rows with dates like 24/07/1998 (day=24) will parse correctly. Rows like 03/09/2006 are ambiguous — Pandas treats them as MM/DD. Document this limitation in your summary.
