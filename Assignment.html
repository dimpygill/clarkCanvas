Build Something with Flask & Jinja

Open-choice project • Build next week • Present to the class

Your goal

Create a small, working Flask website that uses Jinja to display dynamic information. Choose any topic that interests you. The main purpose is hands-on learning: understand how Python data reaches an HTML template and appears in the browser.

What counts as basic?

One working page is enough. For example, Python can calculate a result or prepare a message, pass it to a template, and let Jinja display it. More pages and features are welcome, but are not required.

What your project needs

  • A working Python Flask application with at least one route.
  • An HTML template that receives data from Python and displays it using Jinja.
  • Some Python and Jinja code that you write yourself and can explain.
  • A project you can run and demonstrate from beginning to end.

Use Jinja variables, loops, or if statements as your idea requires. You do not have to use all of them. Template loops and conditions belong to Jinja; Flask handles the request and renders the template with your data.

Your creative choices

Pandas, CSV, JSON, forms, loops, conditions, databases, and multiple pages are optional. You do not need an AI or machine-learning feature. CSV and JSON are data formats; Pandas is a tool you may use to work with data. Choose only what helps your idea.

Using AI

You may use AI to help create an HTML form, page layout, or CSS styling. Write the Python logic, data loading if used, Flask-to-template data passing, and Jinja display logic yourself. Be ready to identify the parts you wrote and any AI-assisted layout or styling.

Example ideas

  • A greeting page that displays a Python-generated message.
  • A study-hours calculator that shows its result on a page.
  • A book, recipe, or product collection.
  • A CSV product viewer, like the included sample.

Sample: CSV Product Viewer

The separate sample_project folder includes a complete runnable example. It reads fictional products from products.csv using Python's built-in csv module, passes those records through Flask, and uses a Jinja loop to display an HTML table. A basic Jinja if/else also shows In stock or Out of stock. The sample demonstrates variables, a loop, and a condition so you can see different possibilities. You do not need to include all of these in your own project; a smaller working example is acceptable. Pandas is not needed. This is one possible project, not the required topic.

Flow: Browser request → Flask route → read CSV → pass records to template → Jinja builds HTML → browser displays the table.

Use the sample to understand the flow. If you choose a similar idea, write and personalize your own implementation instead of submitting the sample unchanged.

Class presentation

  1. Explain what your website does and demonstrate it running.
  2. Show where its data comes from: Python variables, calculations, form input, or a file.
  3. Point out the Flask route and how it sends data to the template.
  4. Show the Jinja expression, loop, or condition that displays the data.
  5. Explain a small section you wrote and one thing you learned.

What to submit

  • A ZIP containing your Python code, templates folder, any CSS or data files, and requirements.txt.
  • A short README with the purpose, setup/run steps, and any AI assistance used.
  • A screenshot of your working page.

Do not include your virtual environment folder or passwords/API keys.

How to approach the work

Keep the scope manageable. The focus is your learning, a working Flask/Jinja connection, and your ability to explain it—not an elaborate design or a long feature checklist. By the end, you should be able to answer: What is Jinja? Where does the data come from? How does Flask pass it to the template? How does that template turn it into visible HTML?
