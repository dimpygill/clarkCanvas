Create • View • Add • Update • Remove • Sort • Read and save CSV • Upload

1. Essential terms

  • pandas: a Python library for working with tables.
  • DataFrame: a table object containing rows and columns.
  • Series: a one-dimensional collection; selecting one DataFrame column usually produces a Series.
  • Row: one record, such as one student.
  • Column: one attribute, such as Name or GPA.
  • Index: the labels attached to rows. Default labels are 0, 1, 2, and so on. A StudentID column is separate from the index unless you explicitly make it the index.
  • Header: a row in a CSV containing column names.
  • Function: an operation such as pd.read_csv(), provided by pandas.
  • Method: an operation on an object, such as df.head().
  • Attribute: information accessed without parentheses, such as df.shape.

Every worked example below contains a complete program. Run examples separately. Local outputs were checked with pandas 2.2.3; display details can vary across versions.

3. Create a DataFrame

A Python dictionary uses keys and values. In {"Name": ["Asha", "Ben"]}, "Name" is a key, and the list ["Asha", "Ben"] is its value. Square brackets define a list; curly braces define this dictionary. pd.DataFrame() converts it to a table.

  • Each dictionary key becomes a column name.
  • Each list provides that column’s values.
  • Lists must have equal lengths.
  • The first items across all lists form the first row.

Example 1: Create from a dictionary of lists

Display the DataFrame with its default row index.

Complete program

import pandas as pd

data = {
    "StudentID": [101, 102, 103],
    "Name": ["Asha", "Ben", "Cara"],
    "Age": [18, 20, 19],
    "GPA": [3.8, 3.2, 3.9]
}
df = pd.DataFrame(data)

print(df.to_string())

Expected output

   StudentID  Name  Age  GPA
0        101  Asha   18  3.8
1        102   Ben   20  3.2
2        103  Cara   19  3.9

5. Add rows and columns

pd.concat() joins tables. ignore_index=True gives the joined table fresh row labels. This avoids accidentally overwriting a row with an existing label. Older examples using df.append() should use pd.concat() instead.

Example 15: Add one row

Build a one-row DataFrame, then join it to the existing table.

Complete program

    "StudentID": [101, 102, 103],
    "Name": ["Asha", "Ben", "Cara"],
    "Age": [18, 20, 19],
    "GPA": [3.8, 3.2, 3.9]
}
df = pd.DataFrame(data)

new_row = pd.DataFrame([{"StudentID": 104, "Name": "Dev", "Age": 22, "GPA": 3.1}])
df = pd.concat([df, new_row], ignore_index=True)
print(df.to_string(index=False))

       103 Cara   19  3.9

9. CSV files and headers — the important differences

Reading a CSV loads data into memory. Saving a DataFrame writes data to a file. Sending data to Airtable uploads data over the network.

GoalOptionWhat happens
Use the file’s first line as column namesheader=0 (usual default)The header line is not a data record.
Read a file with no headerheader=NoneFirst line remains data; columns are labeled 0, 1, 2…
Name columns in a headerless fileheader=None, names=[...]First line remains data; supplied names label columns.
Replace an existing file headerheader=0, names=[...]Original header is consumed and supplied names replace it.
Skip the header and use numbered columnsskiprows=1, header=NoneFirst physical line is skipped; data is preserved.
Hide headings when printingto_string(header=False)Affects displayed text only.
Write a file without headingsto_csv(header=False)Affects the saved CSV only.

A DataFrame always has column labels. “Remove headers” can mean skip a file header, replace column labels, hide headings in output, or save without a header. These are separate tasks. Using header=None on a file that already has a header will treat that header as an ordinary data row.

10. Missing values and duplicates

11. Prepare DataFrame data for Airtable

Airtable stores records in tables inside a base. Its Web API is an interface your Python program uses to send requests. A POST request creates records. JSON is the structured format used for the request body.

  1. Create an Airtable base and a table named Students.
  2. Create fields matching the DataFrame: StudentID (Number, integer), Name (Single line text, suitable as primary field), Age (Number, integer), GPA (Number, decimal).
  3. Find your base ID (app...) and table ID (tbl...) in Airtable’s API documentation or table URL.
  4. Create a personal access token at Airtable’s token page.
  5. Add the data.records:write scope and grant access to this base. Your Airtable account must also be allowed to edit the table. Reading records is a separate operation requiring data.records:read.

Field names must match exactly. StudentID is your own field; it is different from Airtable’s generated record ID (rec...).

Example 50: Prepare missing values for JSON

import os
import json
import time
import pandas as pd
import requests

# Keep credentials out of your program source.
token = os.environ["AIRTABLE_TOKEN"]
base_id = os.environ["AIRTABLE_BASE_ID"]
table_id = os.environ["AIRTABLE_TABLE_ID"]

# Load and validate the CSV before sending anything.
df = pd.read_csv("students.csv")
columns = ["StudentID", "Name", "Age", "GPA"]
missing_columns = [name for name in columns if name not in df.columns]
if missing_columns:
    raise ValueError(f"Missing columns: {missing_columns}")
df = df[columns].copy()
if df["StudentID"].isna().any() or df["StudentID"].duplicated().any():
    raise ValueError("StudentID must be present and unique in this file.")
for name in ["StudentID", "Age", "GPA"]:
    df[name] = pd.to_numeric(df[name], errors="raise")

# Missing optional values become None, then are omitted from fields.
clean = df.astype(object).where(pd.notna(df), None)
records = clean.to_dict(orient="records")
airtable_records = []
for record in records:
    fields = {}
    for key, value in record.items():
        if value is not None:
            fields[key] = value
    airtable_records.append({"fields": fields})

url = f"https://api.airtable.com/v0/{base_id}/{table_id}"
headers = {"Authorization": f"Bearer {token}"}

# Airtable allows at most 10 records per create request.
uploaded = 0
for start in range(0, len(airtable_records), 10):
    batch = airtable_records[start:start + 10]
    payload = {"records": batch}
    json.dumps(payload, allow_nan=False)  # Check JSON compatibility.
    response = requests.post(url, headers=headers, json=payload, timeout=30)
    if not response.ok:
        raise RuntimeError(
            f"Upload stopped after {uploaded} records. "
            f"HTTP {response.status_code}: {response.text}"
        )
    uploaded += len(response.json()["records"])
    if start + 10 < len(airtable_records):
        time.sleep(0.25)
print(f"Uploaded {uploaded} records.")

Expected output after a successful upload

Uploaded 3 records.

This is conditional output: the upload code was syntax-checked, but no live Airtable request was made. With the required permissions, matching fields, and a successful response, the three student records appear in your Airtable table.

Running this again creates new Airtable records. A matching StudentID does not automatically update an existing record. This create-only example is not a synchronization or upsert program. If an upload stops after some batches or a network timeout, inspect Airtable before rerunning; records may already have been created.

13. Understand the upload program

Code / termMeaning
os.environ[...]Read settings from the process environment. Missing settings raise KeyError.
Authorization: Bearer ...Send the access token as authentication. Bearer is the required authentication scheme.
recordsThe list of Airtable record objects in the body.
fieldsA dictionary mapping Airtable field names to values.
range(0, ..., 10)Start a batch at positions 0, 10, 20, and so on.

Airtable supports up to 10 records per ordinary create request and limits requests per base. If a 429 rate-limit response occurs, follow Airtable’s documented waiting guidance before retrying. Do not automatically retry an uncertain create request after a network failure.

14. Common errors

  • ModuleNotFoundError: install packages into the same interpreter used to run the program.
  • FileNotFoundError: check the terminal folder and filename. Use import os; print(os.getcwd()) to see the working directory.
  • KeyError for a column: inspect list(df.columns); names are case-sensitive.
  • First student missing after CSV loading: a headerless file needs header=None.
  • Header appears as a student: the file already has a header; use header=0, including when supplying replacement names.
  • A row was overwritten: assigning to an existing loc label updates that row. Use concat to add rows safely.
  • Update seems lost: avoid chained assignment. Use a single df.loc[condition, column] = value statement.
  • Airtable 401: check the token and authentication.
  • Airtable 403: check token scope, base access, and account/table/field permissions.
  • Airtable 404: verify the base/table IDs and that the token can access the resource.
  • Airtable 422: inspect the response body for field-name, field-type, or invalid-value problems.
  • Airtable 429: the rate limit was exceeded; follow documented waiting guidance.
