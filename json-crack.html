Create JSON from a Python dictionary and save to a file

The most common starting point — you have data in a Python dictionary and want to convert it to JSON. json.dumps() converts to a string; json.dump() writes directly to a file.

example1_create.py
import json

# Step 1: Create a Python dictionary
student = {
    "id": 101,
    "name": "Alice",
    "age": 21,
    "major": "Computer Science",
    "courses": [
        {"course": "Python",   "grade": "A"},
        {"course": "Database", "grade": "B+"}
    ],
    "address": {
        "city": "Seattle",
        "state": "WA"
    }
}

# Step 2: Convert dictionary to JSON string (indent=4 makes it readable)
json_string = json.dumps(student, indent=4)

# Step 3: Print it — copy this output into JSON Crack
print(json_string)

# Step 4: Save to a .json file
with open("student.json", "w") as file:
    json.dump(student, file, indent=4)

print("\nstudent.json saved successfully!")
Output — paste this into JSON Crack
{
    "id": 101,
    "name": "Alice",
    "age": 21,
    "major": "Computer Science",
    "courses": [
        {"course": "Python",   "grade": "A"},
        {"course": "Database", "grade": "B+"}
    ],
    "address": {
        "city": "Seattle",
        "state": "WA"
    }
}

student.json saved successfully!

What each function does

json.dumps(data, indent=4)Converts a Python dict to a JSON string. indent makes it human-readable.
json.dump(data, file)Writes JSON directly to an open file. No intermediate string needed.
indent=4Adds 4 spaces of indentation per level — makes the structure match what JSON Crack shows.

Read a JSON file and access its values in Python

Once JSON is in a file, json.load() reads it back into a Python dictionary. You then access fields exactly like any other dictionary — with square brackets or .get().

example2_read.py
import json

# Step 1: Read the JSON file back into Python
with open("student.json", "r") as file:
    student = json.load(file)    # JSON file → Python dictionary

# Step 2: Access top-level fields (same as any Python dict)
print("Name:",  student["name"])       # Alice
print("Age:",   student["age"])        # 21
print("Major:", student["major"])     # Computer Science

# Step 3: Access a nested field (one level deeper)
city = student["address"]["city"]
print("City:",  city)                   # Seattle

# Step 4: Loop through a nested list
print("\nCourses:")
for c in student["courses"]:
    print(f"  {c['course']} — Grade: {c['grade']}")

# Step 5: Use .get() to safely read a field that might not exist
email = student.get("email", "not provided")
print("\nEmail:", email)                 # not provided (no crash)
Output
Name:  Alice
Age:   21
Major: Computer Science
City:  Seattle

Courses:
  Python — Grade: A
  Database — Grade: B+

Email: not provided

Key concepts

json.load(file)Reads a JSON file and returns a Python dict. Different from json.loads() which parses a string.
data["key"]Access a field directly. Raises KeyError if the key doesn't exist.
data.get("key", default)Safely access a field — returns the default value instead of crashing if the key is missing.
data["address"]["city"]Chain brackets to reach nested values. JSON Crack's graph makes this chaining visible.

Work with deeply nested JSON

Real-world JSON from APIs is often several levels deep. This example shows how to build it, navigate it, and why JSON Crack is especially helpful once the nesting gets past two levels.

example3_nested.py
import json

# Deeply nested structure — 3 levels deep
school = {
    "school": "Tech University",
    "department": {
        "name": "Computer Science",
        "head": "Dr. Smith",
        "courses": [
            {
                "code": "CS101",
                "title": "Intro to Python",
                "students": [
                    {"id": 1, "name": "Alice", "grade": "A"},
                    {"id": 2, "name": "Bob",   "grade": "B"}
                ]
            },
            {
                "code": "CS201",
                "title": "Databases",
                "students": [
                    {"id": 3, "name": "Carol", "grade": "A+"}
                ]
            }
        ]
    }
}

# Navigate the nested structure level by level
dept = school["department"]                     # level 1
print("Dept:",   dept["name"])

first_course = dept["courses"][0]              # level 2
print("Course:", first_course["title"])

first_student = first_course["students"][0]   # level 3
print("Student:", first_student["name"])

# Loop through all courses and students
print("\nAll enrollments:")
for course in dept["courses"]:
    for s in course["students"]:
        print(f"  {s['name']} → {course['code']} → {s['grade']}")

# Print as JSON — paste into JSON Crack
print("\n--- Paste below into JSON Crack ---")
print(json.dumps(school, indent=4))

Course:  Intro to Python
Student: Alice

All enrollments:

    "school": "Tech University",

Read, modify, and write JSON

Load a JSON file, change it in Python, and save it back. This is how configuration files, simple data stores, and cached results work.

example4_modify.py
import json

# Step 1: Start with some existing data and save it
students = {
    "students": [
        {"id": 1, "name": "Alice", "grade": "A"},
        {"id": 2, "name": "Bob",   "grade": "B"}
    ]
}
with open("students.json", "w") as f:
    json.dump(students, f, indent=4)
print("Original saved.")

# Step 2: Read it back
with open("students.json", "r") as f:
    data = json.load(f)

# Step 3: Modify — update Alice's grade
data["students"][0]["grade"] = "A+"

# Step 4: Add a new field to every student
for s in data["students"]:
    s["passed"] = True

# Step 5: Append a new student to the list
data["students"].append({
    "id": 3,
    "name": "Carol",
    "grade": "A",
    "passed": True
})

# Step 6: Save the updated version back to the same file
with open("students.json", "w") as f:
    json.dump(data, f, indent=4)

# Print result — paste into JSON Crack to see what changed
print(json.dumps(data, indent=4))
print("\nstudents.json updated!")
Updated JSON output
Original saved.
{
    "students": [
        {"id": 1, "name": "Alice", "grade": "A+", "passed": true},
        {"id": 2, "name": "Bob",   "grade": "B",  "passed": true},
        {"id": 3, "name": "Carol", "grade": "A",  "passed": true}
    ]
}

students.json updated!

The read-modify-write pattern

json.load()Load file into memory as a Python dict
data[key] = valueModify the dict in memory (file unchanged so far)
list.append(item)Add a new item to a JSON array
json.dump(data, file)Overwrite the file with the modified dict

Parse a real API response string

When your code calls an API, the response arrives as a JSON-formatted string — not a Python dict. json.loads() (with an s) parses it into a dict you can work with. This example simulates exactly what happens in a real API call.

example5_api.py
import json

# This simulates the raw JSON string your code gets from an API.
# In a real app: api_response_string = requests.get(url).text
api_response_string = """
{
    "status": "success",
    "records": [
        {
            "id": "rec001",
            "fields": {
                "Name": "buy milk",
                "Category": "Grocery",
                "Done": false
            }
        },
        {
            "id": "rec002",
            "fields": {
                "Name": "finish assignment",
                "Category": "Task",
                "Done": true
            }
        },
        {
            "id": "rec003",
            "fields": {
                "Name": "call dentist",
                "Category": "Personal",
                "Done": false
            }
        }
    ],
    "total": 3
}
"""

# Step 1: Parse the JSON string → Python dictionary
data = json.loads(api_response_string)   # note: loads (with s), not load

# Step 2: Check status before reading data
if data["status"] == "success":
    print(f"Fetched {data['total']} records\n")

    # Step 3: Loop through records
    # Note: data is 2 levels deep — record["fields"]["Name"]
    for record in data["records"]:
        name     = record["fields"]["Name"]
        category = record["fields"]["Category"]
        done     = record["fields"]["Done"]
        icon     = "✓" if done else "○"
        print(f"  {icon}  [{category}]  {name}")

# Step 4: Filter — only show incomplete items
print("\nStill to do:")
todo = [r for r in data["records"] if not r["fields"]["Done"]]
for r in todo:
    print(f"  - {r['fields']['Name']}")

# Step 5: Print as formatted JSON — paste into JSON Crack
print("\n--- Paste into JSON Crack ---")
print(json.dumps(data, indent=4))
Output
Fetched 3 records

  ○  [Grocery]   buy milk
  ✓  [Task]      finish assignment
  ○  [Personal]  call dentist

Still to do:
  - buy milk
  - call dentist
The key insight: notice record["fields"]["Name"], not just record["Name"]. The field you want is nested inside a fields object. When this gives a KeyError, paste the full response into JSON Crack and the graph immediately shows you exactly how deep your key actually is.

json.loads() vs json.load()

json.loads(string)Parses a JSON string into a dict. Use this with API responses.
json.load(file)Reads a JSON file into a dict. Use this when reading a .json file from disk.
response.json()The requests library calls json.loads() automatically — use this in real API calls.
