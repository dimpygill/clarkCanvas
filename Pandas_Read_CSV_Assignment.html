Load and Display Student CSV Data with pandas

Goal: Read student records from a CSV file into a pandas DataFrame and display the data stored in that DataFrame.

Before you begin

  1. Save the provided students.csv file in your project folder.
  2. Open that folder in VS Code.

    3. Input file: students.csv

    The file contains 10 records and these five columns:

    ColumnMeaning
    StudentIDStudent identifier
    NameStudent name
    AgeAge in years
    MajorArea of study
    GPAGrade point average

    Your task

    1. Create a Python file named load_students.py.
    2. Import pandas using the alias pd.
    3. Use the pandas read_csv() function to read students.csv.
    4. Store the returned DataFrame in a variable named students.
    5. Display all 10 records from the students DataFrame, including all five column headings.
    6. Hide the DataFrame’s row index labels in the displayed output.
    7. Run your program and compare the result with the expected output below.

    Display hint: A DataFrame’s to_string(index=False) method formats the entire table as text without displaying the row index labels. Use print() to display that text. This does not remove the index from the DataFrame.

    Run your program

    Open the terminal in the folder containing both files and run:

    python load_students.py
