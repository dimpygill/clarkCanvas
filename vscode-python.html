Setup guide

Run Python in VS Code.

A step-by-step walkthrough — from a fresh machine to running your first Python file. Check off each step as you go.

7 steps
~15 minutes
Windows & Mac
Install Python

Download the latest Python installer from the official site and run it.

python.org/downloads
⚠ Windows: During installation, check "Add Python to PATH" on the very first screen before clicking Install. If you miss this, Python won't be recognised in the terminal.
Python 3.12.x Installer
Python 3.12.4 (64-bit) Setup ☑ Install launcher for all users ☑ Add Python 3.12 to PATH ← check this! [ Install Now ] [ Customize installation ]

After installing, verify it worked by opening any terminal and running:

python --version

You should see something like Python 3.12.4. On Mac you may need python3 --version.

Install VS Code

Download VS Code from Microsoft's official site. Choose the version for your operating system.

code.visualstudio.com

Install with all default settings. On Windows, optionally check "Add to PATH" so you can open VS Code from the terminal with code .

Tip: "Add to PATH" during the VS Code installer is a convenience, not required. Unlike Python, skipping it won't break anything.
Install the Python extension

VS Code is a general editor — it needs an extension to understand Python. Open VS Code and install the official Microsoft Python extension.

1

From the sidebar

Click the Extensions icon (four squares) on the left sidebar → search Python → install the one published by Microsoft.

2

From the keyboard

Press Ctrl+Shift+X (Windows) or Cmd+Shift+X (Mac) to open Extensions directly.

Extensions: Marketplace
Search Extensions in Marketplace ────────────────────────────────── Python Microsoft · 120M+ installs IntelliSense, linting, debugging, Jupyter Install
What this gives you: syntax highlighting, auto-complete (IntelliSense), the ability to run files with a click, linting (underlines mistakes), and debugger support.
Open your project folder

VS Code works best when you open a whole folder, not just a single file. This lets it understand your project structure, find imports, and activate virtual environments automatically.

A

From the menu

File → Open Folder → navigate to your project directory → click Select Folder.

B

From the terminal (if VS Code is on PATH)

Navigate to your folder in any terminal, then run:

code .
Always open a folder, not a file. If you double-click a .py file to open it, VS Code won't know where your project root is. File → Open Folder is the right habit.
Create or open a .py file

In the Explorer panel on the left, click the New File icon and name it hello.py. Then write some Python:

hello.py — my-project
# hello.py print("Hello, world!") name = "Ada" print(f"Hello, {name}!") for i in range(3):     print(f"Count: {i}")

Make sure the file is saved (Ctrl+S) before running. VS Code shows a dot on the tab if there are unsaved changes.

Select your Python interpreter

VS Code needs to know which Python to use — you might have multiple versions, or a virtual environment. Tell it explicitly.

1

Command Palette

Press Ctrl+Shift+P → type Python: Select Interpreter → choose from the list.

2

Status bar

Click the Python version shown in the bottom-right corner of VS Code — same picker appears.

Select Interpreter
Enter interpreter path or pick one below ★ Python 3.12.4 ('base': conda) Python 3.12.4 ('.venv': venv) ← use this for Flask projects Python 3.10.0 /usr/bin/python3
For Flask projects: always select the .venv interpreter from your project folder, not the global Python. That way VS Code uses the same packages as your terminal.
Run the file

Three ways to run a Python file in VS Code — pick whichever fits the moment:

1

Right-click → Run Python File in Terminal

Simplest. Right-click anywhere in the open .py file and choose this option.

2

Play button (▶) — top right corner

One click. Same as option 1 but faster once you know the keyboard layout.

3

Terminal → python filename.py

Most control. Open the terminal with Ctrl+`, then type the command. This is how you'll run Flask apps.

hello.py — my-project
print("Hello, world!") name = "Ada" print(f"Hello, {name}!")
Terminal
$ python hello.py Hello, world! Hello, Ada! Count: 0 Count: 1 Count: 2 $ |
For Flask specifically: don't use the play button — use the terminal. Activate your .venv first ((.venv) shows in the prompt), then run python app.py. The server needs the terminal to stay open while it runs.

Common errors & fixes

'python' is not recognized as an internal or external command
Cause: Python wasn't added to PATH during installation. Fix: Re-run the installer and check "Add Python to PATH". On Mac, try python3 instead of python.
ModuleNotFoundError: No module named 'flask'
Cause: The package isn't installed in the currently active environment. Fix: Make sure your .venv is active (check for (.venv) in the prompt), then run pip install -r requirements.txt.
SyntaxError: invalid syntax
Cause: A typo in your Python code — a missing colon, mismatched bracket, or misspelled keyword. Fix: VS Code underlines the problem in red. Click on the red underline or check the Problems panel (Ctrl+Shift+M) to find the line number.
pip is not recognized / pip : command not found
Cause: In PowerShell, the .venv was activated with activate.bat instead of Activate.ps1, so the venv's Scripts folder isn't on PATH. Fix: Run .venv\Scripts\Activate.ps1 in PowerShell, or switch to Command Prompt and use .venv\Scripts\activate.bat.
Changes to my .py file aren't showing up when I run it
Fix: Save the file first — Ctrl+S. If the tab name shows a dot (●) next to it, the file has unsaved changes. Python runs whatever is on disk, not what's in the editor buffer.
