Data Cleaning with Python

From messy raw data → reliable, validated, analysis-ready data

Learning goal: Understand data cleaning as a deliberate process: inspect the data, identify problems, decide appropriate rules, clean carefully, validate the result, and document what changed.

1. What Is Data Cleaning?

Data cleaning is the process of identifying and correcting problems in a dataset so that the data is accurate, consistent, usable, and appropriate for its intended purpose.

Real-world data is rarely perfect. A student dataset, for example, may contain missing GPAs, duplicated students, phone numbers written in different formats, spaces around names, impossible GPAs such as 7.5, inconsistent majors such as CS, Computer Science, and computer science, or dates stored in several formats.

Raw Data → Inspect → Identify Problems → Define Rules → Clean → Validate → Save Clean Data
Important: Data cleaning is not the same as deleting anything unusual. An unusual value may be valid. Cleaning decisions should be based on the meaning of the data and the rules of the problem domain.

3. The Complete Data-Cleaning Process

StageQuestionTypical Actions
1. UnderstandWhat should each field mean?Define valid ranges, formats, required fields, unique identifiers.
2. LoadDid Python read the data correctly?Read CSV/Excel/database data; inspect encoding and delimiters.
3. InspectWhat problems exist?Check shape, columns, types, nulls, duplicates, ranges, categories.
4. StandardizeAre equivalent values represented consistently?Trim text, normalize case, standardize categories, dates and phone numbers.
5. Correct typesAre numbers/dates actually stored as numbers/dates?Convert strings to numeric/date types; handle failed conversions.
6. Missing dataWhat should happen when a value is absent?Keep, remove, fill, infer, or flag—depending on context.
7. DuplicatesAre records repeated?Identify exact and logical duplicates; decide which record to retain.
8. ValidateAre values logically possible?Check ranges, allowed categories, relationships and business rules.
9. OutliersAre extreme values errors or legitimate observations?Investigate; correct, retain, cap, transform, or flag as appropriate.
10. Verify & exportDid cleaning create new problems?Re-run checks, compare counts, preserve raw data, save cleaned output.

4. Load the Dataset with Pandas

import pandas as pd

# Read the CSV file and store it in a DataFrame called df
df = pd.read_csv("students.csv")

# Display the first 5 rows
print(df.head())

A DataFrame is a table-like structure in pandas. Rows usually represent observations/records, while columns represent variables or fields.

5. Always Inspect Before Cleaning

5.1 Look at rows

print(df.head())       # First 5 rows
print(df.tail())       # Last 5 rows
print(df.sample(5))    # Random sample of 5 rows

5.2 Check size

print(df.shape)

If the result is (1000, 5), there are 1,000 rows and 5 columns.

5.3 Check column names

print(df.columns)

5.4 Check data types

print(df.dtypes)

5.5 Get a summary

df.info()
print(df.describe())
print(df.describe(include="all"))
Rule: Do not immediately start changing the data. First understand what Python loaded and what the dataset is supposed to represent.

6. Clean Column Names

Column names can contain spaces, inconsistent capitalization, or punctuation.

# Example original names:
# "Student Name", " Phone ", "GPA"

# Remove leading/trailing spaces
df.columns = df.columns.str.strip()

# Convert names to lowercase
df.columns = df.columns.str.lower()

# Replace spaces with underscores
df.columns = df.columns.str.replace(" ", "_")

print(df.columns)

Result: student_name, phone, gpa.

7. Clean Text Data

7.1 Remove extra spaces

df["name"] = df["name"].str.strip()
BeforeAfter
"  John Smith  ""John Smith"

7.2 Standardize capitalization

# Names
# "JOHN SMITH" → "John Smith"
df["name"] = df["name"].str.strip().str.title()

# Example category normalization
# "DATA SCIENCE" → "data science"
df["major"] = df["major"].str.strip().str.lower()

7.3 Remove repeated internal spaces

# "John    Smith" → "John Smith"
df["name"] = df["name"].str.replace(r"\s+", " ", regex=True)

8. Standardize Categories

The same concept may appear under several labels.

# First normalize text
df["major"] = df["major"].str.strip().str.lower()

# Map equivalent labels to one standard label
major_map = {

    "comp sci": "Computer Science",

df["major"] = df["major"].replace(major_map)

Find unexpected categories

print(df["major"].value_counts(dropna=False))

9. Missing Values

Missing values may appear as truly empty cells or text such as N/A, unknown, -, or not available.

9.1 Convert missing-value labels while loading

df = pd.read_csv(
    "students.csv",
    na_values=["N/A", "NA", "Unknown", "unknown", "not available", "-"]
)

9.2 Detect missing values

print(df.isna())
print(df.isna().sum())

9.3 Option A: Remove rows

# Remove rows where ANY value is missing
df = df.dropna()

# Better: remove only when a critical field is missing
df = df.dropna(subset=["name"])

9.4 Option B: Fill missing values

# Fill missing major with a label
df["major"] = df["major"].fillna("Unknown")

# Fill missing numeric value with median
median_gpa = df["gpa"].median()
df["gpa"] = df["gpa"].fillna(median_gpa)
Do not automatically replace every missing numeric value with 0. A missing GPA does not necessarily mean the student's GPA is 0.0. Missing means unknown/unavailable unless the domain explicitly defines otherwise.

9.5 Option C: Keep and flag missing data

df["gpa_missing"] = df["gpa"].isna()

This preserves information that the value was originally missing.

10. Correct Data Types

10.1 Numeric conversion

A GPA column might be read as text because one row contains three point five.

# Convert values to numbers.
# Invalid values become NaN instead of crashing the program.
df["gpa"] = pd.to_numeric(df["gpa"], errors="coerce")

errors="coerce" means: if pandas cannot convert a value to a number, replace it with a missing value (NaN).

10.2 Integer types with missing values

df["student_id"] = pd.to_numeric(df["student_id"], errors="coerce").astype("Int64")

10.3 Be careful with IDs and phone numbers

A phone number is composed of digits, but it is generally an identifier/text value, not a quantity. You do not add or average phone numbers.

11. Clean Phone Numbers

These may all represent valid numbers but use different formats:

5035551234
503-555-1234
(503) 555-1234
503.555.1234

Remove non-digits

# Keep only digits
phones = df["phone"].astype("string").str.replace(r"\D", "", regex=True)

df["phone"] = phones

Validate length

# For this example, assume US 10-digit phone numbers
valid_phone = df["phone"].str.len() == 10

print(df[~valid_phone])

Format consistently

def format_phone(phone):
    if pd.isna(phone):
        return pd.NA

    if len(phone) == 10:
        return f"{phone[0:3]}-{phone[3:6]}-{phone[6:10]}"

    return pd.NA


df["phone"] = df["phone"].apply(format_phone)
International data: Do not assume every phone number has 10 digits if your dataset includes multiple countries. Country codes and international formatting require different validation rules.

12. Clean Dates

Dates frequently arrive in mixed formats:

05/12/2004
2004-05-12
May 12, 2004
05-12-2004
# Convert values to actual datetime values.
# Values that cannot be interpreted become NaT.
df["date_of_birth"] = pd.to_datetime(
    df["date_of_birth"],
    errors="coerce"
)
Date ambiguity: 05/12/2004 can mean May 12 or December 5 depending on the convention. Do not guess when the source format is ambiguous. Determine the expected format first.

When the exact source format is known

# Example: source is guaranteed to use MM/DD/YYYY
df["date_of_birth"] = pd.to_datetime(
    df["date_of_birth"],
    format="%m/%d/%Y",
    errors="coerce"
)

Export dates consistently

df["date_of_birth"] = df["date_of_birth"].dt.strftime("%Y-%m-%d")

13. Find and Remove Duplicates

13.1 Exact duplicates

# Show duplicated rows
print(df[df.duplicated()])

# Remove exact duplicates
df = df.drop_duplicates()

13.2 Duplicates based on selected columns

# A student ID should uniquely identify a student
print(df[df.duplicated(subset=["student_id"], keep=False)])

# Keep the first occurrence
df = df.drop_duplicates(subset=["student_id"], keep="first")
Be careful: Two students can have the same name. Do not treat identical names as duplicates unless your domain rules justify it. Prefer a reliable unique identifier such as Student ID.

14. Validate Numeric Ranges

Suppose GPA must be between 0.0 and 4.0.

# Find invalid GPAs
invalid_gpa = (df["gpa"] < 0) | (df["gpa"] > 4)

print(df[invalid_gpa])

Option: mark invalid values as missing

df.loc[invalid_gpa, "gpa"] = pd.NA

Do not silently "fix" values without evidence

If GPA is 7.2, we do not know whether the intended value was 3.2, 2.7, or something else. It is safer to flag the record for review than invent a correction.

15. Validate Allowed Values

Suppose the only accepted enrollment quarters are Fall, Winter, Spring, and Summer.

allowed_quarters = ["Fall", "Winter", "Spring", "Summer"]

invalid_rows = ~df["quarter"].isin(allowed_quarters)

print(df[invalid_rows])

You can first normalize case:

df["quarter"] = df["quarter"].str.strip().str.title()

16. Find Outliers

An outlier is a value unusually far from other observations. It is not automatically an error.

Example: IQR method

Q1 = df["age"].quantile(0.25)
Q3 = df["age"].quantile(0.75)
IQR = Q3 - Q1

lower_limit = Q1 - 1.5 * IQR
upper_limit = Q3 + 1.5 * IQR

outliers = df[
    (df["age"] < lower_limit) |
    (df["age"] > upper_limit)
]

print(outliers)
Outlier ≠ error. A 70-year-old college student may be statistically unusual but completely valid. Statistical detection tells you what to investigate; domain knowledge tells you what action is appropriate.

17. Logical and Cross-Field Validation

Some errors cannot be found by checking one column independently.

Example: graduation year before enrollment year

invalid = df["graduation_year"] < df["enrollment_year"]
print(df[invalid])

Example: future birth dates

today = pd.Timestamp.today()
future_birth_dates = df["date_of_birth"] > today
print(df[future_birth_dates])

This is called a business rule or domain validation rule: the values may have valid data types but still make no logical sense together.

18. Email Cleaning and Validation

# Normalize obvious formatting issues
df["email"] = df["email"].str.strip().str.lower()

# Simple structural check (not a guarantee that the mailbox exists)
valid_email = df["email"].str.match(
    r"^[^\s@]+@[^\s@]+\.[^\s@]+$",
    na=False
)

print(df[~valid_email])
A regex can check whether an email looks structurally plausible. It cannot prove that the email account actually exists.

19. Cleaning Currency and Numeric Text

Values such as $1,250.50 cannot be directly analyzed as numbers if stored as strings.

# Remove dollar signs and commas
df["tuition"] = (
    df["tuition"]
      .str.replace("$", "", regex=False)
      .str.replace(",", "", regex=False)
)

# Convert to numeric
df["tuition"] = pd.to_numeric(df["tuition"], errors="coerce")

20. Negative Numbers and Impossible Values

# Example: age cannot be negative
invalid_age = df["age"] < 0
print(df[invalid_age])

# Example rule for this particular dataset
invalid_age = ~df["age"].between(14, 100)
print(df[invalid_age])

The correct range depends on the dataset. Do not copy arbitrary ranges into a real project without understanding the population.

21. Leading Zeros

ZIP codes, student IDs, and product codes may contain leading zeros:

ZIP Code:  02139
Student ID: 001245

If converted to integers, the leading zeros disappear. Keep such identifiers as strings when those zeros are meaningful.

df = pd.read_csv(
    "students.csv",
    dtype={"student_id": "string", "zip_code": "string"}
)

22. Encoding Problems

Names may contain characters such as José, Zoë, François, 李. Use an appropriate text encoding when reading the file.

df = pd.read_csv("students.csv", encoding="utf-8-sig")

utf-8-sig reads UTF-8 text and also handles the BOM that may appear at the beginning of CSV files exported by some applications such as Excel.

23. Do Not Modify Raw Data Permanently

Best practice: Preserve the original raw file. Cleaning should produce a separate cleaned dataset so you can reproduce or audit your work.
# Read raw data
raw_df = pd.read_csv("students_raw.csv")

# Make a working copy
df = raw_df.copy()

# ...clean df...

# Save separately
df.to_csv("students_clean.csv", index=False)

24. Validate After Cleaning

Cleaning is not finished when the code stops producing errors. Recheck the result.

# Check dimensions
print(df.shape)

# Check missing values
print(df.isna().sum())

# Check duplicates
print("Duplicates:", df.duplicated().sum())

# Check data types
print(df.dtypes)

# Check GPA range
print(df["gpa"].min())
print(df["gpa"].max())

# Check categories
print(df["major"].value_counts(dropna=False))

Use assertions for important rules

# Stop the program if the rule is violated
assert df["student_id"].is_unique
assert df["gpa"].dropna().between(0, 4).all()

25. Keep an Audit Trail

For important projects, record what was changed rather than making invisible modifications.

print("Rows before cleaning:", len(raw_df))
print("Rows after cleaning:", len(df))
print("Rows removed:", len(raw_df) - len(df))

You can also create flags rather than immediately deleting suspicious records:

df["invalid_gpa"] = ~df["gpa"].between(0, 4)
df["missing_phone"] = df["phone"].isna()

This example combines several common cleaning steps. The exact rules should always be adapted to the dataset.

import pandas as pd

# ---------------------------------------------------------
# STEP 1: LOAD DATA
# ---------------------------------------------------------

df = pd.read_csv(
    "students_raw.csv",
    encoding="utf-8-sig",
    na_values=["N/A", "NA", "Unknown", "unknown", "not available", "-"]
)

# ---------------------------------------------------------
# STEP 2: INSPECT DATA
# ---------------------------------------------------------

print(df.head())
print(df.shape)
print(df.dtypes)
print(df.isna().sum())

# ---------------------------------------------------------
# STEP 3: CLEAN COLUMN NAMES
# ---------------------------------------------------------

df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")

# ---------------------------------------------------------
# STEP 4: CLEAN NAMES
# ---------------------------------------------------------

df["name"] = df["name"].str.strip()
df["name"] = df["name"].str.replace(r"\s+", " ", regex=True)
df["name"] = df["name"].str.title()

# ---------------------------------------------------------
# STEP 5: CLEAN GPA
# ---------------------------------------------------------

# Convert GPA to numeric; invalid text becomes NaN
df["gpa"] = pd.to_numeric(df["gpa"], errors="coerce")

# GPA must be from 0 through 4
invalid_gpa = ~df["gpa"].between(0, 4) & df["gpa"].notna()

# Mark impossible GPA values as missing
df.loc[invalid_gpa, "gpa"] = pd.NA

# ---------------------------------------------------------
# STEP 6: CLEAN MAJOR
# ---------------------------------------------------------

df["major"] = df["major"].str.strip().str.lower()

major_map = {
    "cs": "Computer Science",
    "computer science": "Computer Science",
    "comp sci": "Computer Science",
    "ds": "Data Science",
    "data science": "Data Science"
}

df["major"] = df["major"].replace(major_map)

# ---------------------------------------------------------
# STEP 7: CLEAN PHONE NUMBERS
# ---------------------------------------------------------

df["phone"] = (
    df["phone"]
      .astype("string")
      .str.replace(r"\D", "", regex=True)
)

# Keep only 10-digit numbers for this US-only example
invalid_phone = df["phone"].notna() & (df["phone"].str.len() != 10)
df.loc[invalid_phone, "phone"] = pd.NA

# ---------------------------------------------------------
# STEP 8: REMOVE DUPLICATES
# ---------------------------------------------------------

df = df.drop_duplicates()

# ---------------------------------------------------------
# STEP 9: VALIDATE
# ---------------------------------------------------------

print("Missing values:")
print(df.isna().sum())

print("Duplicate rows:", df.duplicated().sum())
print("GPA minimum:", df["gpa"].min())
print("GPA maximum:", df["gpa"].max())

# ---------------------------------------------------------
# STEP 10: SAVE CLEAN DATA
# ---------------------------------------------------------

df.to_csv("students_clean.csv", index=False)

print("Data cleaning completed.")

28. Common Mistakes in Data Cleaning

MistakeWhy it is risky
Deleting every row with any missing valueMay discard large amounts of useful information.
Replacing every missing number with 0Zero and unknown have different meanings.
Automatically deleting all outliersExtreme observations may be legitimate.
Guessing correctionsChanges the underlying information without evidence.
Using names alone to detect duplicatesDifferent people can share a name.
Converting IDs to integersCan destroy leading zeros and identifier formatting.
Overwriting the raw datasetRemoves your ability to reproduce or audit cleaning.
Cleaning without validating afterwardYour cleaning code itself can introduce errors.

31. Final Concept

Good Data Cleaning = Understanding + Detection + Appropriate Decisions + Transformation + Validation + Documentation

The most important skill is not memorizing pandas functions. It is learning to ask: What does this value mean? What values are valid? Is this truly an error? What evidence supports the correction? How can I verify that my cleaning worked?
